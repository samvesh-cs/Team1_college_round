BIT 1 cursorMath.js — Pure Math Functions

File to create: src/content/cursor/cursorMath.js

No webcam, no DOM, no MediaPipe. Just testable math functions.

Functions to Implement

FunctionSignatureWhat it does
calibrate (landmarkX, landmarkY) Stores the "neutral" reference point (where nose = screen center)
getDelta (currentX, currentY) → {dx, dy} Returns difference from neutral position
applyDeadZone (delta, deadZone) → number Returns 0 if |delta| < deadZone, else returns delta
applySmoothing (prev, current, factor) → number EMA: factor × prev + (1 − factor) × current
mapToViewport (delta, sensitivity, center, size) → number Converts delta to a pixel position on screen
clamp (value, min, max) → number Clamps value between min and max

// ✅ Expected: 0

console.log(applyDeadZone(0.05, 0.02));   // outside dead zone
// ✅ Expected: 0.05

// --- Test applySmoothing ---

// ✅ Expected: 0.3 × 100 + 0.7 × 200 = 170

// ✅ Expected: 960 + (0.05 × 15 × 1920) = 2400

// ✅ Expected: 1920  (clamped to max)

// ✅ Expected: 0  (clamped to min)

console.log(clamp(500, 0, 1920));
// ✅ Expected: 500  (within range, unchanged)

BIT 2 faceTracking.js — Webcam + MediaPipe

File to create: src/content/cursor/faceTracking.js

⚠️ Prerequisite: Run npm install @mediapipe/tasks-vision before starting this bit.

What it does

  • Initializes MediaPipe FaceLandmarker from @mediapipe/tasks-vision
  • start(callback) — requests webcam via getUserMedia, starts detection loop, calls callback({ x, y }) every frame with nose-tip landmark (index 1 of 478 points)
  • stop() — stops camera tracks, cleans up landmarker

🧪 Test Code — Add temporarily to content.js

});

  console.log("Tracking stopped.");

BIT 3 cursorController.js — The Cursor Moves!

File to create: src/content/cursor/cursorController.js

What it does

  • Creates the #handsfree-cursor div in the DOM
  • On each frame: landmark → getDelta → applyDeadZone → mapToViewport → applySmoothing → clamp → update cursor.style.left/top
  • Mirrors X axis (negate deltaX so right head = right cursor)
  • Exposes: start(), stop(), pause(), resume(), calibrate()
🚨 CAUTION: Do NOT use React state for per-frame cursor updates. Update element.style.left/top directly. React re-renders at 60fps will kill performance.

🧪 Test Code — Add temporarily to content.js

BIT 4 content.js Wiring — Handle Chrome Messages

File to modify: src/content/content.js

What to change

In the onMessage listener, handle each MSG type and delegate to CursorController:

MSG constantActionTrigger
MSG.START_TRACKINGcursor.start()User clicks "Start Engine"
MSG.STOP_TRACKINGcursor.stop()User clicks "Stop Engine"
MSG.PAUSE_CURSORcursor.pause()User toggles tracking off
MSG.RESUME_CURSORcursor.resume()User toggles tracking on
MSG.CALIBRATEcursor.calibrate()User clicks "Calibrate"
