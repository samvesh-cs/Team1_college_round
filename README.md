# Handsfree

Handsfree is an accessibility-focused project that allows users to interact with their computers without relying entirely on a keyboard or mouse. It uses voice commands, head movements, and hand gestures to make computer navigation easier and more accessible.

## Features

- **Cursor Control:** Move the cursor using head movements or hand gestures.
- **Voice Navigation:** Use voice commands to click, scroll, open links, and switch tabs.
- **Voice Typing:** Type text by speaking into a microphone.
- **Intentional Activation:** Help prevent accidental clicks and commands by requiring intentional activation.
- **Hands-Free Interaction:** Navigate and interact with supported computer interfaces with minimal physical input.

## Goal

The goal of Handsfree is to make digital experiences more accessible, convenient, and easier to use for people who have difficulty using traditional input devices.
